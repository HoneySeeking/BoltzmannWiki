# Size
- For simplicity of game mechanic, sizes are divided up into discrete categories
- The average size for player characters is expected to be about the size of a raccoon, about a meter long, but controlling about a 1 meter square in the combat grid, if using the grid

| Mouse Size    | 1/4 meters  | 1d4 per 2 meters | 1/2                          | 1                   | 1 medium                        |
| Raccoon Size  | 1 meter     | 1d6 per 2 meters | 1                            | 1                   | 2 large                         |
| Wolf Size     | 2 meters    | 1d6 per meter    | 2                            | 1                   | 8 large                         |
| Bear Size     | 3 meters    | 2d6 per meter    | 3                            | 1                   | 32 large                        |
