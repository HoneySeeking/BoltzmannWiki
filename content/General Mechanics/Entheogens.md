# Entheogens
- Essential for [[Rituals]], helpful for [[Spells]]
- The creators of Boltzmann TTRPG do not endorse the consumption of entheogens IRL

# Doses
- When taking entheogens, first roll a Vitality check against the associated number to not throw up (the dose is ruined if you fail)
- If successful, add the number to your PRE checks for the duration
- Use the associated number as weights when combining smaller doses into larger doses

| Dosage     | Value | Description                                                                                                                       |
| ---------- | ----- | --------------------------------------------------------------------------------------------------------------------------------- |
| Small      | 1-3   | Mildly altered perception. Interaction physical world is augmented.                                                               |
| Large      | 4-15  |              #todo                                                                                                                     |
| Heroic     | 16-63 | Complete spiritual and mental dislocation, a direct experience of the spitit realm. The soul is visibly bleeding out of the body. |
| Ridiculous | 64+   |  Usually taken in error: such quantities have potentially injurious effects. Those that survive the experience are left raving about demons no one else can see and an all encompassing spider web.                                                                                                                                 |


# Duration
- if using for a ritual, enough for that ritual
- otherwise, the faster of 10 minute timer on the table or 1 hour in fiction
- Additional doses before it expires simply overwrites the previous entheogen clock and dose
