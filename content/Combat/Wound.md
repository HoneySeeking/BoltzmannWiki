Each wound decreases sizes of all attributes by 1.

# Healing
## Natural Healing
Wounds heal according to the following table.

| Number of Wounds | Healing Duration (days) |
| ---------------- | ----------------------- |
| 1                | Cd4                     |
| 2                | Cd6                     |
| 3                | Cd8                     |
| 4                | Cd10                    |
| 5 and more       | Cd12                    |
So for example when you have 4 wounds, after the end of a long rest, you roll a d10 for healing. If the countdown dice rolls a 1, one point of wound is healed and next day, you roll a d8 and so on. Note that this abstraction represents the wound stabilizing enough such that you return to effectiveness, but in the game fiction, it may not be completely healed for months to years, with continued pain and/or scarring.
